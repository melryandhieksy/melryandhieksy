## 🚀 Projetos

### 🍴 Sistema de Cantina

Sistema desenvolvido para auxiliar na organização e gerenciamento
de uma cantina.

O projeto busca reunir funcionalidades para facilitar o controle
das informações e a organização do estabelecimento.

---

### 🏠 Projeto de Casa Inteligente

Projeto acadêmico envolvendo Internet das Coisas, automação e
uma representação de uma casa inteligente.

A proposta é integrar dispositivos e sensores para demonstrar
como a IoT pode ser aplicada em ambientes cotidianos.

---

### 📚 Sistema de Repertório para ENEM

Projeto voltado para organização e estudo de repertórios para
redação do ENEM.

A ideia é utilizar tecnologia para tornar o processo de estudo
mais organizado e interativo.
